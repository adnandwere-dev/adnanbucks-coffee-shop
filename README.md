# ☕ AdnanBucks

A modern coffee shop web application built with **Next.js 16**, **React 19**, and **Tailwind CSS**.

AdnanBucks is a portfolio project inspired by premium coffee shop experiences. It focuses on delivering a clean UI, responsive design, smooth user interactions, and modern frontend development practices.

---

## ✨ Features

- Modern and responsive UI
- Product catalog
- Product details page
- Shopping cart
- Checkout page
- Product search
- Multiple product variants (size & milk options)
- Persistent cart using Local Storage
- Dark theme
- Fast page loading with Next.js App Router

---

## 🛠 Tech Stack

- Next.js 16 (App Router)
- React 19
- Tailwind CSS
- Lucide React
- JavaScript (ES6+)

## 📦 Installation

Clone the repository

```bash
git clone https://github.com/yourusername/adnanbucks.git
```

Go to the project folder

```bash
cd adnanbucks
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Build for production

```bash
npm run build
```

Start production server

```bash
npm run start
```
